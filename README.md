# 打卡小助手

手机浏览器打开后，默认全月上班，点日期勾选休息；也可点「反选休息日」。页面会显示「不休息天数」，工资按「当月总天数 - 休息天数」计算。数据保存在 Mac 的 `projects/ayi-pay/data.json`，手机与 Mac 打开同一地址时使用同一份数据。

## 打开

双击 `打开阿姨工资助手.command`，会自动用 Chrome 打开并启动本机服务。

## 手机访问

手机连接同一个 WiFi 后访问服务启动时显示的地址，例如：

`http://10.0.72.163:4399`

## 备份

页面里的「导出备份 / 导入备份」可保存和恢复 JSON 文件；换电脑时直接复制 `data.json` 也可以。
